Refine and deepen the current Hamrahe profile experience based on the existing design.

Recommended model: Claude Opus 4.6

Important:
The current profile already includes many core modules such as:
- profile header
- about
- experience
- skills
- recommendations
- featured / portfolio
- activity
- profile score / progress style indicators

Do NOT redesign these sections from scratch.
Do NOT treat them as missing.

Instead, strengthen and refine them so the profile becomes a more credible, decision-oriented professional identity system.

## Main Goal

Transform the current profile from a strong-looking professional page into a more structured and actionable decision surface for:
- recruiters
- hiring managers
- collaborators
- companies
- the user themselves

The refined profile should help others quickly understand:
- who this person is
- what they are genuinely good at
- why they are credible
- what kinds of opportunities they are ready for

## 1. Refine the Existing Header

Do not replace the current header concept.

Improve it by making it:
- more hierarchy-driven
- easier to scan quickly
- more professional and decision-oriented

Strengthen:
- work availability states
- trust / credibility indicators
- profile strength / readiness logic
- quick action clarity
- relationship between identity and opportunity signals

The header should feel like a professional command card.

## 2. Refine the Existing About Section

Do not redesign About from scratch.

Improve its readability and strategy.

Make it feel:
- more structured
- easier to scan
- less like a generic paragraph
- more useful for recruiters and collaborators

Clarify:
- specialization
- value proposition
- industry focus
- collaboration preference

## 3. Refine the Existing Experience Section

Do not just list jobs.

Strengthen the current experience presentation so it becomes more outcome-oriented.

Improve:
- hierarchy between role, company, and impact
- visibility of achievements
- readability for recruiter scanning
- emphasis on contribution and measurable outcomes where possible

## 4. Refine the Existing Skills Section

The skills section already exists.
Do not rebuild it as a basic list.

Instead:
- improve hierarchy
- make stronger or more trusted skills more visible
- make endorsements feel more meaningful
- prepare the visual logic so this area could later evolve into a deeper skill graph

## 5. Refine the Existing Recommendations Section

Recommendations already exist in the current profile direction.

Improve them so they feel:
- more like professional testimonials
- more credible
- more important to trust-building

Clarify:
- recommender identity
- recommender role
- recommendation weight and visibility

Also improve the UX for requesting recommendations.

## 6. Refine the Existing Featured / Portfolio Section

This section already exists and should be strengthened, not replaced.

Make it feel:
- more central to the profile
- more evidence-based
- more useful for evaluating capability

Improve:
- card structure
- visual hierarchy
- sense of proof, not just presentation
- connection between work samples and professional credibility

## 7. Refine the Existing Profile Completion Logic

The current profile already has score / progress / completion signals.

Do not replace them with a simple progress bar.

Instead:
- make completion more actionable
- show why each missing part matters
- connect profile completion to visibility, trust, and opportunity readiness
- make it feel like an improvement engine, not just a checklist

## 8. Strengthen Embedded Smart Suggestions

Add or refine embedded guidance inside the profile.

Suggestions should feel:
- contextual
- professional
- helpful
- connected to profile quality and opportunity readiness

Examples:
- improve visibility by adding stronger skills
- strengthen trust by requesting recommendations
- improve job readiness by completing experience
- add featured work to support credibility

## 9. Strengthen Resume Logic in the Profile Architecture

Do not design a separate resume export flow yet.

But refine the profile structure so it clearly feels:
- organized
- structured
- exportable in the future
- compatible with Persian and English resume formats

## 10. Refine the Existing Professional Indicators

The current design already includes score / signal / trust-style elements.

Improve them by making them:
- cleaner
- less noisy
- less gamified
- more recruiter-friendly
- more clearly separated into:
  - trust / credibility
  - responsiveness
  - visibility
  - readiness

## Design Goals

The profile should feel:
- more credible
- more structured
- more evidence-based
- more useful for decision-making
- more professional than a normal social profile
- more dynamic than a static resume

## Important Constraints

- Do NOT redesign the entire product
- Do NOT rebuild the profile from zero
- Work with the existing profile direction and improve it
- Keep the platform web-first for this phase
- Make the profile scalable for future mobile adaptation
