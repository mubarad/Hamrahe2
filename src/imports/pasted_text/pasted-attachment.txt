Design a complete high-fidelity Figma experience for the “Learning & Assessments” system of Hamrahe, a professional network for Iran’s digital economy.

Important:
Use the existing Hamrahe UI style, visual language, layout patterns, spacing, colors, cards, navigation, typography, components, and interaction patterns as the source of truth.

Do not invent a completely new visual system.
Do not redesign Hamrahe from scratch.
The interface should feel native to the current Hamrahe product.

Let Figma decide the exact UI layout, component composition, spacing, and visual treatment based on the existing Hamrahe design system, while strictly preserving the product logic described below.

Language:
- Design the full product in Persian.
- Use RTL layout.
- Keep English only for necessary product terms like AI, Career Path, Assessment, Skill Graph, Talent Pool, Readiness, Certificate.
- Tone: professional, clear, premium, modern, trustworthy.
- Do not make it look like a school, LMS, Udemy, Coursera, LinkedIn Learning clone, or generic video-course platform.

Core Product Philosophy:
Hamrahe Learning is not video-based.
Hamrahe Learning is AI-native, interactive, practice-first, career-path-based, assessment-first, and deeply integrated across the product.

Hamrahe does not teach old workflows with new AI tools.
Hamrahe teaches the new logic of professional work in an AI-native world.

LinkedIn Learning teaches through content consumption.
Hamrahe teaches through AI-guided practice, real-world simulation, AI output critique, assessment, feedback loops, and measurable career readiness.

Main Formula:
One Career Path
Assessment-First Integrated Learning
AI-Native Role Logic
Interactive Practice
Product-Wide Integration
Multiple Optional Outcomes

Very Important Product Logic:
Do not design Assessment as a separate isolated product section.

Assessment is not a separate product island.
Assessment is the starting point, diagnostic engine, validation mechanism, and progress checkpoint inside the integrated Learning experience.

Users may start their journey through an assessment, but the assessment must immediately connect to:
- Career Path
- Skill gaps
- AI-native skill gaps
- Recommended AI practice
- Role readiness
- Application readiness
- Certificate eligibility
- Job readiness
- Company profile
- Talent Pool
- Partner opportunities

The experience should feel like one continuous flow:

Assessment
→ Skill Gap
→ Recommended Career Path
→ AI Practice
→ AI Feedback
→ Revision
→ Re-assessment
→ Readiness Update
→ Certificate
→ Job / Talent Pool / Partner Opportunity

Do not create a separate “Assessment Home” that feels disconnected.
Create an integrated “Learning & Assessments” experience where Assessment triggers Learning actions and Learning progress updates Assessment, Readiness, Skill Graph, Certificate, Job Match, and Talent Pool signals.

Core Experience:
The user should always understand:
- Where am I now?
- What is my current level?
- What skills am I missing?
- What should I practice with AI?
- What Career Path phase should I continue?
- What assessment should I complete?
- How does this improve my readiness?
- Which jobs or companies become more relevant after this?
- What can I share, and what stays private?

Design Principles:
- Use Hamrahe’s existing design system as the source of truth.
- Assessment is the starting point, not a separate island.
- Learning and Assessment must feel like one continuous experience.
- AI is not decoration; AI is the engine of learning.
- Assessment should diagnose and guide, not just score.
- Every assessment result must recommend learning or practice.
- Every learning completion must improve readiness or profile signal.
- Every certificate must be based on performance, not passive completion.
- Every sensitive result must have privacy and consent controls.
- Every partner introduction must be optional.
- Every user action should create a smarter next action.
- Keep the UI clean, integrated, professional, and not overloaded.

Do not include:
- Video course pages
- Generic course marketplace design
- Instructor-centered education
- Old-school LMS layout
- Separate isolated Assessment product
- Empty badge decoration
- Overloaded dashboards
- Unclear privacy behavior
- Fake AI visuals without product logic
- A new visual design unrelated to current Hamrahe UI
